# PowerBI-Sales-Analysis
"Interactive Power BI dashboard for analyzing Global Superstore sales by region, category, and month. Created as part of Task 8 for Data Analyst Internship."
 <br>

##  Objective <br>
To build a simple, interactive Power BI dashboard showcasing sales performance by product category, region, and time (Month-Year). <br>

## Tools Used <br>
- Power BI Desktop <br>
- Dataset: Global_Superstore2.csv <br>

## KPIs Displayed <br>
- Total Sales <br>
- Total Profit <br>
- Average Order Value (AOV) <br>

## Visuals Included <br>
- Line Chart: Sales over Months <br>
- Bar Chart: Sales by Region <br>
- Donut Chart: Sales by Category <br>
- Slicers: Region and Category <br>

## Key Insights <br>
1. Central region leads in sales with 2.8M+ compared to other regions. <br>
2. Furniture and Technology are the top-selling categories. <br>
3. Average Order Value is ₹25.9M, indicating high-value orders. <br>
4. Sales show a consistent upward trend with seasonal peaks. <br>

## Files Included <br>

- `Global_Superstore_Sales_Insights.pptx`: Insights in slide format <br>
- `Sales_insight_dashboard.pdf`: Visual proof of the dashboard <br>
